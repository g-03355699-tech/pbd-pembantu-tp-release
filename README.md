# PBD Pembantu TP — Muat Turun

Chrome extension untuk membantu guru mengisi Sistem PBD KPM (SPPB): TP dari markah peperiksaan, isian pukal, Ulasan Guru, Usaha Murid dan Ulasan Guru Kelas.

## ⬇️ [Muat turun versi terkini (zip)](https://github.com/g-03355699-tech/pbd-pembantu-tp-release/raw/main/pbd-pembantu-tp.zip)

## 📘 [Manual Pengguna (PDF)](https://github.com/g-03355699-tech/pbd-pembantu-tp-release/raw/main/Manual-PBD-Pembantu-TP-v1.9.1.pdf)

Panduan lengkap 24 halaman: pemasangan, isi TP dari markah, isian pukal, Ulasan Guru & Usaha Murid, Ulasan Guru Kelas, langganan, kemas kini dan penyelesaian masalah.

Versi semasa: lihat [`latest.json`](latest.json). Versi lama ada dalam folder [`versi/`](versi/).

## Pemasangan kali pertama
1. Muat turun zip di atas dan unzip ke satu folder tetap (cth. `Documents\pbd-pembantu-tp`).
2. Chrome → `chrome://extensions` → hidupkan **Developer mode**.
3. **Load unpacked** → pilih folder `pbd-pembantu-tp`.
4. Pin ikon **TP** pada toolbar.

## Langganan
- **Percuma:** Import (Excel/CSV/markah → TP), isian Pukal, Eksport.
- **Langganan:** Ulasan Guru, Usaha Murid, Ulasan Guru Kelas.
- Untuk melanggan: buka popup → klik **🔒 Versi percuma · Langgan** di bawah → tekan **💬 WhatsApp** atau **✉️ Emel** (Kod Peranti disertakan automatik). Anda akan menerima kod langganan untuk ditampal dan diaktifkan.
- Kod langganan diikat pada satu komputer. Jika extension dibuang dan dipasang semula, Kod Peranti berubah dan kod baharu diperlukan (kemas kini biasa tidak menjejaskannya).

## Kemas kini
Apabila ada versi baharu, popup extension akan memaparkan notis kuning.
1. Klik **Muat turun versi baharu**.
2. Unzip dan **gantikan fail dalam folder yang sama** (tetapan anda akan kekal).
3. `chrome://extensions` → tekan ↻ **Reload** pada PBD Pembantu TP.
4. Tekan F5 pada halaman PBD.

> Extension ini tidak menekan butang Simpan/Hantar utama. Sentiasa semak sebelum menyimpan. Semua data murid diproses dalam pelayar sahaja.
